# IBIS — Information Budget Insight System

IBIS is a web portal that gives university libraries a clear view of what they
spend on scholarly information. It aggregates expenditure data from existing
source systems and presents it along the modules of the
[modular reference model](https://doi.org/10.5281/zenodo.13828013) for information
budgets (Meistring, Ferguson, Pampel & Vleugel 2025).

The reference model defines six modules:

1. Expenditure on information supply
2. Expenditure on publication production
3. Expenditure on services and framework contracts
4. Expenditure on infrastructure and operations
5. Staff costs
6. Sources of funding (income)

IBIS in its first stage covers modules **1**, **2** and **4**.
